# Архитектура мультиагентного помощника

```mermaid
flowchart TD
    A[Сообщение пользователя] --> B[Модель GigaChat]
    B --> C{Анализ тона и контента}
    C -->|Эмоциональная поддержка| D[support_agent]
    C -->|Конкретные советы| E[advice_agent]
    C -->|Нехватка мотивации| F[motivation_agent]
    C -->|Запрос юмора| G[humor_agent]
    C -->|Нужен пинок| H[coach_agent]
    C -->|Общие вопросы| I[general_agent]
    
    I --> J[Запоминает имя пользователя]
    J --> K[Персонализирует ответы]
```
